## Balatro3DS

[English](README.md) | **简体中文**

Balatro3DS 是一款由爱好者制作、面向 Nintendo 3DS 平台的 Balatro 移植/实现版本，使用 Lua 和 LÖVE 构建。

### 运行要求

- 一台支持运行自制软件的 Nintendo 3DS
- Node.js（可选，用于在开发过程中运行本地化校验）

### 开始使用

#### 操作方式

- 确认/选择：A
- 取消/弃牌/出售：B
- 出牌/使用/购买并使用：X
- 排序/刷新商店：Y
- 显示小丑牌：L
- 显示消耗牌：R
- 打开牌组视图：Select
- 暂停：Start

可以在 **暂停 > 设置 > 控制** 中重新绑定按键。

#### 语言

Balatro3DS 目前支持：

- 英语（`en`），作为后备语言
- 简体中文（`zh_CN`）

可以在 **暂停 > 设置 > 语言** 中切换显示语言。所选语言会按玩家档案保存并立即生效，
当前使用的字体也会随之切换。

#### 在 3DS 上运行

你可以下载已经发布的版本。

##### 使用打包版本

1. 从 Releases 页面下载一个发布版本
2. 将 `Balatro3DS.3dsx` 文件复制到 SD 卡根目录下的 `3ds` 文件夹中
3. 打开 Homebrew Launcher
4. 开始游戏

##### 从源码构建

Windows 自动打包脚本的用法以及 Linux/macOS 手动构建流程请参阅
[BUILD.zh-CN.md](BUILD.zh-CN.md)。

### 本地化开发

本地化架构、键名规范、字体要求和质量检查清单记录在
[LOCALIZATION.md](LOCALIZATION.md) 中。

提交本地化改动前，请运行仓库校验：

```sh
node check_localization.js
```

校验工具会检查语言文件的键名和占位符、UTF-8 源文件、词条覆盖情况，以及主要 UI 模块中
直接绘制的英文字符串。

### 许可证

本项目按现状提供，仅用于教育和爱好者用途。重新分发前，请查看仓库中的许可证文件了解详情。
